# Security Policy

## Reporting a Vulnerability

Security, reliability, and responsible vulnerability disclosure are important to BackSeat.

If you discover a potential security vulnerability, please report it privately through the repository's security reporting feature:

**[Report a Vulnerability — BackSeat](https://github.com/ATLURI0001/BackSeat/security/advisories/new)**

Please include:

- A clear description of the vulnerability.
- Affected components and versions.
- Steps to reproduce the issue.
- Potential security or safety implications.
- Relevant logs or supporting evidence.
- Suggested mitigations, if available.

## Responsible Disclosure

Please avoid publicly disclosing unpatched vulnerabilities before maintainers have had a reasonable opportunity to investigate them.

Do not expose sensitive credentials, personal information, or private vehicle data.

## Security Priorities

BackSeat prioritizes vulnerabilities affecting:

- Vehicle communication and control interfaces.
- Authentication and access control.
- Software integrity and update mechanisms.
- Data handling and privacy.
- System isolation and privilege management.
- Safety-critical software components.

## Security Response

Reports will be reviewed according to their severity, reproducibility, and potential impact.

Acknowledgment and remediation timelines are not guaranteed.

## Scope

This policy applies to security issues involving the BackSeat repository and its maintained components.

Third-party dependencies may have separate security reporting procedures.

## Safety Notice

BackSeat contains experimental driver-assistance software. Security review does not constitute vehicle safety certification or approval for public-road deployment.
